| D44 | Platt fit stopping rule (completes the Stage 10 R1 method before any val-B score exists; no ADR, as for D37/D42). Keep the absolute gradient rule (‖g‖ < 1e-10) and add: stop when the Newton decrement λ²/2 = −½·gᵀd ≤ 1e-12, with d the Newton direction (Boyd and Vandenberghe 2004, §9.5.1); raise ValueError ("stalled") if an accepted line-search step leaves (a, b) unchanged, and ValueError if the Newton direction is not a descent direction (λ²/2 < −1e-12), so the new stop can never accept a non-optimal point silently. Everything else in `fit_platt` is unchanged (smoothed targets, start point, Armijo line search, 100-iteration cap, a > 0). Reason: on synthetic val-B-shaped separable logits the absolute rule raised "did not converge" on converged fits (334 of 1,260 fits in the committed pre-check, `docs/audit_evidence/stage10_d44/`, at every score scale; the count moves by about one fit across platforms because it depends on float64 rounding, which is the defect itself), because the computed gradient stalls at float64 resolution above 1e-10 once steps stop changing (a, b); on real val-B this would surface only after scoring and force a post-hoc change. λ²/2 approximates f − f* and does not depend on the score scale; 1e-12 is about 100× the worst float64 noise floor measured in that pre-check (9.7e-15).
